暂无符合条件的本土骨科植入物生产厂家

经多维度检索（监管注册、行业协会、上市公司、细分品类、展会与企业数据库）与官网逐一核查， 未在 孟加拉 发现符合「本土注册 + 自有工厂 + 实际生产骨科植入物」严格标准的生产厂家。

该市场以进口经销为主。按名录规则，无生产能力的经销商、进口代理商与外资销售子公司一律不纳入本表，故此处不列企业，绝不以经销商凑数。

核查结论：暂无符合条件的本土骨科植入物生产厂家。孟加拉国骨科植入物市场几乎完全依赖进口(85%+)，搜索结果中的'厂家'绝大多数为中国出口商的SEO页面、进口贸易商，或像United Surgical这样的美资OEM支具/耗材工厂。Cross-check行业与DGDA相关线索后，未发现注册于孟加拉、拥有自有工厂并实际生产骨科植入物(脊柱/关节/创伤板钉/外固定器等)的本土企业。
已核查并剔除（部分）：United Surgical Ltd (USB, Dhaka)——美资跨国公司的合同制造(OEM)子公司(American Owned, 总部Fort Wayne)，核心业务为骨科支具/护具(support & braces/softgoods)、注塑与一次性耗材，非本土资本且非骨科植入物(板/钉/螺钉)制造，排除；Medico Bangladesh——官网自述'leading Orthopedic Implants Importer and suppliers'，为进口商/贸易商，非制造商，排除；Hospital Medical Laboratory / hospitallaboratory.com——SEO目录壳页面(About页显示为印度医疗设备销售商)，无孟加拉工厂可核实，排除；Getwell Limited (bdebest.com)——目录挂名'Verification Pending'，主营口罩/手套/注射器等耗材，骨科植入物仅为列名，制造能力未核实，排除；Daher / Zynfuse / Moventra / Axiora / Osteora / WEX / Retra / Sete / Medisplint / Marin-one / Horaizon / DTRX / Medicalur 等——均为中国出口商针对孟加拉国市场的SEO落地页，非孟加拉本土厂家，排除；Atlas Surgical (atlasortho.in)——印度公司面向孟加拉市场的出口页面，非本土，排除

数据说明：本表仅列示本土骨科植入物 生产厂家（MANUFACTURER），已严格剔除经销商、进口代理商、外资销售子公司、牙科种植体厂与纯耗材厂。每条附可核查来源，联系方式未公开项统一标注、零虚构。
